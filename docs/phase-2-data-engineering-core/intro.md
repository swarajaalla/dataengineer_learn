# Intro

This phase covers the foundational concepts every data engineer must know before touching a production pipeline.

---

## What You'll Learn

| Section | What it covers |
|---------|---------------|
| **01 – Core Concepts** | What DE actually is, big data, data types, ACID, OLAP vs OLTP |
| **02 – Storage Systems** | Data warehouse, data lake, lakehouse — and when to use each |
| **03 – File Formats** | CSV, JSON, Parquet, Avro, Delta — internals and trade-offs |
| **04 – Data Ingestion** | APIs, batch ingestion, streaming, CDC patterns |
| **05 – Data Processing** | ETL vs ELT, transformations, incremental loads, orchestration |
| **06 – Data Modeling** | Star schema, SCD, medallion architecture |
| **07 – Streaming & Events** | Kafka, event-driven design, Lambda vs Kappa |
| **08 – Architecture Thinking** | Modern data stack, pipeline design, real-world architectures |

---

## Why This Phase Matters

Most data engineering interviews and on-the-job work revolve around these concepts. Without them, you're guessing at architecture decisions and cargo-culting patterns you don't understand.

Every section maps directly to real work: designing a pipeline, choosing a file format, modeling a schema, or explaining an architecture to a senior engineer.

---

## Prerequisites

Before this phase, you should be comfortable with:
- SQL (joins, window functions, aggregations)
- Python (reading files, calling APIs, basic data manipulation)
- Git basics

If not, complete Phase 1 first.
