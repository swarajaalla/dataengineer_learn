# Roadmap to Getting a Data Engineering Job

A no-fluff guide to landing your first (or next) data engineering role.

---

## Realistic Timelines

| Background | Time to First DE Job |
|------------|---------------------|
| Software developer (Java/Python) | 3–6 months |
| Data analyst (SQL-heavy) | 4–8 months |
| BI developer (Power BI/Tableau) | 6–10 months |
| Career changer (non-tech) | 12–18 months |
| Junior DE (upgrade to senior) | 6–12 months |

These are averages with consistent part-time study. Full-time study = half the time.

---

## The Only Things That Get You Interviews

1. **A real portfolio project** with a GitHub repo and architecture diagram
2. **Strong SQL** — tested in almost every first-round screen
3. **Relevant job title / experience** on LinkedIn/resume
4. **Certifications** (DP-203 or Databricks DE Associate) — removes initial screening rejection

Tutorials, courses, and YouTube don't get you interviews. Projects and demonstrated skills do.

---

## Job Search Strategy

### Where to Look

- LinkedIn (most enterprise Azure/Databricks roles)
- Indeed
- Company career pages (target companies that use Azure + Databricks)
- Referrals (highest conversion rate)

### What to Target

For your first DE role:
- Junior/Associate Data Engineer titles
- Data Engineer 1 / Entry-level DE
- Analytics Engineer (dbt-heavy roles — good entry point)
- Data Engineer at a consultancy (broad exposure)

For career upgraders:
- Mid-level / Senior Data Engineer
- Lead Data Engineer
- Platform Engineer (Data)

---

## Application Checklist

Before applying, have:

- [ ] Updated LinkedIn with "Data Engineer" in headline
- [ ] GitHub with at least one real DE project (README + architecture)
- [ ] Resume: impact bullets, no more than 2 pages, relevant skills section
- [ ] DP-203 or Databricks cert (or studying for one)
- [ ] SQL ready: can write window functions, CTEs, anti-joins without looking up

---

## Interview Stages (Typical Enterprise Process)

```
1. HR Screen (30 min)
   → Background, availability, salary expectations

2. Technical Screen (45–60 min)
   → SQL questions (2–3), Python/Spark basics, tool knowledge

3. Technical Interview (60–90 min)
   → SQL challenge, Spark/pipeline design, scenario questions

4. System Design (60 min, senior roles)
   → Design a data pipeline / lakehouse architecture

5. Hiring Manager Interview (45 min)
   → Projects, team fit, experience depth
```

---

## What Interviewers Actually Care About

| They ask... | They're testing... |
|-------------|-------------------|
| "Walk me through a pipeline you built" | Real experience, not tutorial knowledge |
| "How would you handle data quality?" | Production awareness |
| "What would you do if the pipeline failed at 3am?" | Incident handling, monitoring |
| "Why did you choose X over Y?" | Engineering thinking, trade-offs |
| SQL window function question | Daily fundamentals |
| "Tell me about a challenge you faced" | Problem-solving depth |

## Salary Ranges (UK/EU, 2024–2025 approximate)

| Level | London | Rest of UK | EU (Germany/Netherlands) |
|-------|--------|-----------|--------------------------|
| Junior (0–2 yrs) | £45–60k | £35–50k | €45–65k |
| Mid (2–5 yrs) | £65–85k | £50–70k | €65–85k |
| Senior (5+ yrs) | £90–120k | £70–95k | €85–110k |
| Lead/Principal | £120k+ | £95k+ | €110k+ |

Tech companies and finance pay 20–40% above these ranges. Contracting rates are typically 2–2.5x day rate vs permanent salary.
