# DP-203: Azure Data Engineer Associate

Microsoft's primary Azure data engineering certification. Validates skills in ADF, ADLS, Synapse Analytics, Databricks, and stream processing.

---

## What It Covers

| Domain | Weight |
|--------|--------|
| Design and implement data storage | 15–20% |
| Develop data processing | 40–45% |
| Secure, monitor, and optimize data storage and processing | 30–35% |

Key topics:
- Azure Data Factory (pipelines, linked services, datasets, triggers)
- Azure Data Lake Storage Gen2
- Azure Databricks (Spark, Delta Lake)
- Azure Synapse Analytics (dedicated SQL pool, serverless SQL, Spark pools)
- Azure Stream Analytics
- Azure Event Hubs
- Monitoring and performance optimization

---

## Is It Worth Getting?

**Yes** — especially in Azure-focused enterprises. It:
- Validates your Azure DE skills to employers
- Required or preferred in many senior DE job descriptions in EMEA
- Forces you to understand services you might not use daily (Synapse SQL Pool, Stream Analytics)
- Demonstrates commitment to the Azure platform

## Exam Format

- Duration: 120 minutes
- Questions: 40–60 (mix of multiple choice, drag-and-drop, case studies)
- Passing score: 700/1000
- Cost: ~$165 USD
- Valid for: 1 year (renew with free online assessment)

---

## Key Topics to Focus On

**High weight, often tested:**
- ADF: parameterized pipelines, triggers, linked services, copy activity settings
- ADLS: access tiers, RBAC vs ACLs, managed identity vs SAS vs storage key
- Databricks: cluster types, Delta Lake operations (MERGE, OPTIMIZE, VACUUM)
- Synapse: difference between Dedicated SQL Pool and Serverless SQL
- Performance: partitioning, Z-ORDER, broadcast joins, distribution strategies in Synapse

**Commonly missed:**
- Azure Event Hubs partition count and consumer groups
- Stream Analytics window types (tumbling, hopping, sliding, session)
- Synapse Dedicated Pool distribution strategies (Hash, Round Robin, Replicate)
- PolyBase vs COPY INTO in Synapse

## Sample Questions

**Q: You have a large dataset in ADLS. Which distribution strategy in Synapse Dedicated SQL Pool is best for a large fact table?**  
A: Hash distribution on the most-used join column. This collocates related rows on the same node, minimizing data movement during joins.

**Q: You need to load data from ADLS to Synapse Dedicated Pool as fast as possible. Which method?**  
A: COPY INTO statement or PolyBase with CTAS. COPY INTO is simpler and handles most formats.

**Q: You want to fire an ADF pipeline whenever a file lands in ADLS. Which trigger type?**  
A: Storage Event Trigger (Blob Created event).
